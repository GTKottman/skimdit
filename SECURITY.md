# Security policy

## Supported versions

Until 1.0, only the latest release gets security fixes. After 1.0, the latest minor release of the current major version is supported.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue.

Include the Skimdit version, what an attacker can do, and steps to reproduce.

You can expect an acknowledgement within 7 days and a fix or a plan within 30 days. Security fixes take priority over all other work. You will be credited in the release notes unless you ask not to be.
